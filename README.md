# أعمال ومستجدات فريق القمة | أغسطس 2026

موقع التقرير الشهري الرسمي لفريق القمة — React + Vite، بواجهة عربية RTL، بدون
باك-إند أو قاعدة بيانات، جاهز للنشر على GitHub Pages.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```

تُنشأ الملفات النهائية داخل مجلد `dist`.

## النشر على GitHub Pages

المشروع مهيأ بمسار أساس ثابت في `vite.config.js`:

```js
base: '/THETOPTEAM-LY-2026august/'
```

هذا يجب أن يطابق اسم مستودع GitHub بالضبط. إذا غيّرت اسم المستودع، عدّل هذا
السطر ليطابقه.

**الطريقة الأولى — عبر GitHub Actions (تلقائي بالكامل):**

1. ارفع المشروع إلى مستودع GitHub على فرع `main`.
2. من إعدادات المستودع Settings → Pages، اختر Source: **GitHub Actions**.
3. سيقوم الـ workflow الموجود في `.github/workflows/deploy.yml` تلقائيًا ببناء
   المشروع ونشره عند كل دفع (push) إلى `main`.

**الطريقة الثانية — نشر مجلد `dist` فقط إلى فرع `gh-pages`:**

```bash
npm install
npm run deploy
```

هذا الأمر يبني المشروع (`predeploy` يشغّل `npm run build` تلقائيًا) ثم يرفع
محتوى مجلد `dist` فقط إلى فرع `gh-pages` عبر حزمة `gh-pages` (تستخدم git
داخليًا). بعدها من إعدادات المستودع Settings → Pages، اختر Source: **Deploy
from a branch** وحدد الفرع `gh-pages` والمجلد `/ (root)`.

## بنية المشروع

```
src/
  components/   عناصر واجهة قابلة لإعادة الاستخدام
  data/         محتوى المستجدات والمشاريع والروابط (قابل للتعديل بسهولة)
  pages/        الصفحة الرئيسية وصفحة تفاصيل كل مستجد
  sections/     أقسام الصفحة الرئيسية
  assets/       شعار الفريق
```

لتعديل أي مستجد أو مشروع أو رابط، عدّل الملفات داخل `src/data/` مباشرة.
